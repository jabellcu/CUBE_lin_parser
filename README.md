# CUBE_lin_parser

CUBE_lin_parser is a python library that allows to work with CUBE's \*.lin
files programmatically. See demo.ipynb for examples.


# Usage

Download or clone this repository to your working folder. You can then:

    from CUBE_lin_parser import lin_parser

lin_parser will allow you to import a \*.lin file as system. You can then
analyse and edit it's lines and nodes/stops. A system can also be written as
a \*.lin file and used in CUBE.
